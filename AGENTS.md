# AGENTS.md — OrchidCavalry

## ⚠️ GOVERNANCE (applies to every session and every command)

**Do NOT take large-scale actions without asking the user first.**

The user dictates the direction of this game. Before doing anything
large-scale — new features, new quest types, new mechanics, balance changes,
deleting projects or files, architecture or namespace refactors, or anything
that changes the game's rules or direction — **stop and ask the user for
explicit approval first.**

Safe without asking: bug fixes, small cleanups, tests, documentation, build
verification, and committing/pushing that work (see the `/next` command).

When in doubt: ask.
